# Hera TD Demo base

Godot 4.7.2 .NET, C# / .NET 8, Compatibility renderer, 960 × 640.
`Main.tscn` is deliberately empty. `PROMPT.md` is the frozen recording prompt;
game scripts, populated scenes and captures are produced during the run.

## Prepare

Install Godot **4.7.2 .NET** and the **.NET 8 SDK** (the runtime alone is not
enough for Godot's build/reload tooling). Install the published CLI:

```powershell
npm install -g hera-godot@2.0.0
$release = Join-Path (npm prefix -g) 'hera-godot.cmd'
./prepare.ps1 -HeraCli $release
```

Use an explicit npm/Scoop executable if a development shim shadows your PATH.
`prepare.ps1` checks version 2.0.0, copies the root Hera addon, builds the empty
project, and downloads/verifies the released compiler helper. It does not
download the engine or SDK. The addon and helper are not duplicated in Git.
Do not run preparation while the project is open in another editor.

## Rehearse or record

Use a separate profile for rehearsal, following
[DEV_MACHINE.md](../../docs/DEV_MACHINE.md#isolated-live-smoke-pattern): set
`HOME`, `USERPROFILE` and `APPDATA` (also isolate `LOCALAPPDATA`, XDG and
`DOTNET_CLI_HOME`) **before preparation**, and use the same environment for
the CLI/editor. Ensure `dotnet` resolves the .NET 8 SDK. Open this folder in a
GUI editor, enable Hera, turn **Game Feel Mode** and **Game Feel UI Mode** on,
and open `Main.tscn`. Confirm `status --capabilities` identifies this project
and CLI/addon 2.0.0. Keep the user's other editor untouched; select the isolated
editor with `--instance <pid>`.

After the manual intro, start the agent timer and submit only the text inside
`PROMPT.md`'s `text` fence. Count all implementation, builds, fixes and runtime
QA until the final summary. Preparation and asset generation precede that timer.
The rehearsal must finish in eight minutes, use at least two successful C#
command types (eval/validate/run), show moving enemies and tower fire, and keep
the same editor alive through rebuilds. See
[the rehearsal report](../../docs/reports/2026-10-16-demo-td-rehearsal.md).

## Reset to the committed base

Stop the game through Hera and close only the rehearsal editor. From the repo
root, preview the scoped cleanup, then remove generated/ignored files:

```powershell
git restore --worktree -- demo/td-csharp/Main.tscn demo/td-csharp/project.godot
git clean -ndx -- demo/td-csharp/
git clean -fdx -- demo/td-csharp/
```

The cleanup deletes **all untracked files inside this demo folder**, including
the copied addon, generated scripts/scenes and build/import caches. Save any
run you want to retain elsewhere first. Run preparation again before recording.
There are no game scripts or extra scenes in the committed base.

## Sprite provenance

All five 64 × 64 PNG sprites: **generated by Codex, 2026-10-16**, using built-in
ImageGen; nearest-neighbor export to delivery size, preserving sprite alpha.
No external asset packs or fonts. Godot's default font is used.

The generation prompt set used a single top-down pixel-art asset, a logical
64 × 64 grid, burgundy/charcoal colors inspired by Hera's hair and clothing in
`docs/assets/hera-pointing.png`, no text, borders or mockup. Subjects:

| File | Prompt subject | Background |
| --- | --- | --- |
| `tower.png` | Charcoal stone turret, burgundy crystal cannon pointing right, brass accents | Transparent |
| `enemy.png` | Burgundy slime, pale eyes, charcoal outline | Transparent |
| `projectile.png` | Burgundy-magenta bolt flying right, cream core, square sparks | Transparent |
| `ground.png` | Seamless charcoal cobblestone, muted olive details | Opaque |
| `path.png` | Seamless warm taupe flagstones with cracks | Opaque |
