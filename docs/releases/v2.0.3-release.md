# v2.0.3 release

## Change

Docs-only patch. The release tag now carries `docs/guide/index.html` (Hera Godot
Status), a self-contained Korean guide to the request flow, command families,
risks, open questions and decisions. The portfolio site mirrors that file from
release tags to `/hera-godot-status/`, so this is the first tag it can mirror.
Also ships 45a1786, which removed unreachable Go helpers. CLI and addon behavior
are unchanged; the addon manifest moves to `2.0.3` only.

Requested by the owner on 2026-10-21.

## Channels

- GitHub Release: built by `release.yml` from tag `v2.0.3`.
- Scoop, npm (`packaging/npm/manifest.json` hashes) and the Homebrew tap: update
  from the release's `checksums.txt` after the workflow finishes, as in
  [v2.0.2](v2.0.2-asset-store-upload.md). npm publication stays with Victor.
- Asset Store: the addon ZIP differs from 2.0.2 only by the manifest version.
  Uploading it is Victor's call; if uploaded, reuse the v2.0.2 store fields with
  this changelog:

```text
Docs: add the Hera Godot Status guide. No editor or CLI behavior changes.
```
