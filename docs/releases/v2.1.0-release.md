# v2.1.0 release

## Changes

Wave 1 adds read narrowing (`node get --changed`, scoped `scene tree` with
`--depth`, `--type`, `--props`, and `signal list --connected`) and fixes scene
paths escaping the edited scene. Wave 2 combines node creation and properties
with repeatable `node add/instance --set` in one undo action, adds bounded
`game assert --within-ms` retries (QA `within_ms`), and makes `--flag=` behave
like an empty space-separated value under normal validation.

**Breaking default CLI output:** redundant counts/names, false `truncated`, and
status session/path fields are omitted. Missing log `source` means file.
Pretty and batch output share the rules; explicit `--fields` remain honored.
Read the [migration guide](../MIGRATING_TO_V2_1.md) and upgrade CLI/addon together.
Parser isolation, command-file splits, shared value encoding and engine process
helpers preserve behavior while reducing duplication.

## C# and editor features / C#·에디터 기능

- **C# eval, validate and run.** Eval defaults to C# on Godot 4.7+ .NET. Use `SceneRoot` for the edited root. Standard editors return an explicit unavailable error; there is no silent language fallback. Validation builds one root csproj without ProjectReference graphs into isolated output paths (60-second default). Run executes a prebuilt C# SceneTree/MainLoop harness without a GDScript shim.
- **C# 평가·검증·실행.** 새 C# 기능은 Godot 4.7+ .NET 전용입니다. 기본 eval 언어는 C#이며, 표준 에디터에서는 지원 불가 오류와 GDScript 안내를 반환합니다. 검증은 격리 출력 경로로 빌드하고, 실행은 기존 C# 빌드 결과를 사용합니다. 사용자 프로젝트 파일을 생성하거나 수정하지 않습니다.
- **Separate compiler helper.** Install it with `hera-godot csharp-host install`. The command verifies the release SHA256 and replaces the helper under your home directory. npm/Scoop/Homebrew install the CLI only. Eval never downloads a helper automatically. The framework-dependent helper needs .NET 8 or a compatible newer runtime. The native `HeraCSharpEval.cs` loader is entirely `#if TOOLS`-only and excluded from export builds.
- **별도 컴파일러 헬퍼.** `hera-godot csharp-host install`로 설치하세요. SHA256 검증 후 홈 폴더에 설치하며 eval은 자동 다운로드하지 않습니다. `HeraCSharpEval.cs`는 전체가 `#if TOOLS`로 감싸진 에디터 전용 코드입니다.
- **Editor panel.** EN/KO connection, version, C# and auth observations, editor theme/DPI support, and English Copy agent setup. Copy includes project path and auth state but no token value/path. Major/minor comparison is advisory; older CLI requests without a version header show unknown with upgrade guidance.
- **한영 에디터 패널.** 연결·버전·C#·인증 상태와 에이전트 설정 복사를 제공합니다. 복사 내용에는 프로젝트 경로가 있지만 토큰 값과 경로는 없습니다. 버전 비교는 기능 호환성 보장이 아니며 구형 CLI에는 업그레이드를 안내합니다.
- **Engine-backed commands and debug guidance.** Engine info/doctor, script run, project import/export, movie capture, benchmarks and API dumps work without a live Hera editor. GDScript DAP attach/stack/variables/evaluate/steps remain experimental; C# debugging uses the IDE's .NET debugger. Movie capture needs a display driver.
- **엔진 명령과 디버그 안내.** 실행·임포트·익스포트·캡처·벤치마크·API 덤프를 별도 엔진으로 실행합니다. GDScript DAP은 실험적이며 C# 디버깅은 IDE에서 수행합니다.

## Migration / 전환

Existing GDScript expressions must pass `--lang gdscript`, or set `HERA_GODOT_EVAL_LANG=gdscript`. Explicit language wins. v2.1 omits redundant default fields; remaining field types stay unchanged. `game node call` and `eval` expose structured `result_value` or an omission reason alongside the stable string result.

기존 GDScript 식에는 `--lang gdscript`를 붙이거나 `HERA_GODOT_EVAL_LANG=gdscript`를 설정하세요. 명시한 언어가 우선합니다. v2.1은 기본 응답의 중복 필드를 생략하고 남은 필드 타입은 유지하며, 구조화된 결과 또는 생략 사유를 함께 제공합니다.

## Editor and game tools / 에디터·게임 도구

Inspect scenes, nodes, scripts, resources, Theme items and ClassDB. Add/set/reparent/remove nodes, wire signals and save scenes. Supported editor mutations use undo; eval and runtime actions do not. Drive runtime controls and input, pause/step the play clock, capture screenshots at actual viewport size and run requirement-covered QA. Read logs with explicit source and completeness boundaries. Optional receipts, guarded writes and linked evidence help distinguish execution from observation and disk persistence.

씬·노드·스크립트·리소스·테마를 읽고 편집하며, 런타임 입력·화면 캡처·QA 시나리오를 실행합니다. 지원되는 에디터 변경은 undo를 제공하지만 eval과 런타임 변경은 제공하지 않습니다. 로그·작업 영수증·조건부 쓰기·증거 필드로 관측 범위를 구분합니다.

## Execution limits / 실행 경계

Eval is arbitrary synchronous code, not a sandbox or undo operation. A client timeout does not stop a running expression. Non-Tool C# scripts may be placeholders in the editor; retained delegates can prevent ALC unloading and require restart. MSBuild targets and generators execute code; redirected build outputs are not a sandbox. Script run uses a built assembly, which may be stale. Read the C# and security guides before using untrusted projects.

eval은 임의 코드를 동기 실행하며 샌드박스·undo·강제 중단을 제공하지 않습니다. C# placeholder와 ALC 유지로 제약이나 재시작이 발생할 수 있습니다. MSBuild 타깃과 생성기도 코드를 실행하므로 출력 경로 격리는 보안 격리가 아닙니다. 실행 DLL은 최신 소스와 다를 수 있습니다.

## Install / 설치

1. Use Godot 4.2 or later (4.7+ recommended; new C# features require 4.7+ .NET).
2. Copy the addon into `res://addons/hera_agent_godot/` and enable Hera Agent Godot under Project Settings → Plugins.
3. Install the matching CLI; for C# eval, install the separate helper and build/reload the project with the native loader.
4. Run `hera-godot status`, then `hera-godot smoke --skip-game`.

애드온을 복사하고 플러그인을 활성화한 뒤 같은 버전 CLI를 설치하세요. C# eval은 헬퍼 설치와 프로젝트 빌드·리로드가 필요합니다. status와 smoke로 연결을 확인하세요.

Local editor communication uses localhost HTTP with optional token auth. The explicit helper installer downloads from GitHub. No cloud account is required for editor operations. MIT licensed.

에디터 통신은 localhost HTTP와 선택적 토큰 인증을 사용합니다. 명시적 헬퍼 설치 명령은 GitHub에서 다운로드합니다. 에디터 조작에는 클라우드 계정이 필요하지 않습니다. MIT 라이선스입니다.
