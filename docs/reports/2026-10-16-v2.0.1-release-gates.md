or import in progress`. Status is intentionally available while importing, so
status success was not a readiness gate. The CI harness now retries only the
read-only smoke for explicit editor_busy responses (150 attempts, 200ms spacing);
other errors fail immediately. No production mutation retry was introduced.
The candidate's runtime CI job passes with this fix.

Headless editor teardown emits engine RID/ObjectDB/scan-aborted warnings and
optional Blender-path warnings on these engines; passing script checks are not
claims of warning-free engine teardown. The live collector observation above
covers only its registered editor interval. Native macOS/Homebrew installation
was not run on this Windows PC. No npm publish or Asset Store submission.
